# ParkFlow

ParkFlow is a smart parking management platform built to manage parking locations, vehicles, reservations, occupancy, and real-time slot availability.

## Tech Stack

### Backend
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

### Frontend
- React
- Vite
- Tailwind CSS

### Planned Infrastructure
- Redis
- WebSockets
